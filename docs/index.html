GenoDisc Pipeline – Documentation

GenoDisc is an open-source Snakemake pipeline for post-GWAS functional genomics. Starting from GWAS summary statistics, it runs a standardised battery of analyses — fine-mapping, gene-level and transcriptome/proteome-wide association, heritability, and drug-target enrichment — to prioritise the genes, mechanisms, and candidate drugs behind an association signal.

Web platform

Upload summary statistics in your browser. Analyses run on King’s College London servers and results open in an interactive viewer. No installation needed.

Run the pipeline yourself

Install the open-source Snakemake pipeline on your own machine or HPC. Choose this if your data can’t leave your environment, or you need custom references, configuration or batch runs.
